The user recalled a robot roaming around Electromagnetic Field (EMF) Camp several years ago and supplied a video showing the robot and Global Positioning System (GPS) plots. The EMF Roamer project is documented at EMF 2018 and EMF 2022. The sources describe two iterations: a small tracked Raspberry Pi robot in 2018, followed by a much larger quarter-scale wooden Cybertruck in 2022. It is a useful historical example of browser-based remote operation and managed access to a shared robot; it is not an adopted Robots project design.

===== Documented operation =====

The 2018 builder's account describes a small tracked robot based on a Raspberry Pi, with a camera stream, GPS location, and a browser queue for control over the internet. GPS data was sent to a web server and stored in a MySQL database. The author reports 1,632 GPS updates, 3.217918922 miles (approximately 5.18 km) travelled, and 6 hours 19 minutes of video. These are builder-reported event figures, not independently verified measurements. The video supplied by the user is embedded in this account; the article says the GPS-log animation was produced with Excel 3D Maps.

The `roamerpi` repository is a strong match for the 2018 Raspberry Pi build: its owner is Chris Stubbs, the same builder, and its repository description and folders align with the blog's reported Raspberry Pi, control, GPS, and video components. The repository's individual source files and setup instructions could not be retrieved in this review, so its exact version, completeness, and relationship to the later 2022 vehicle remain unverified.

The author also reports that patchy Wi-Fi caused missed stop packets and that the motors could continue moving. A watchdog stopped the motors after a period without new control packets; the author first set this to 3 seconds, then reduced it to 1 second while replacing Hypertext Transfer Protocol (HTTP) control with WebSockets. These are details of that historical build, not recommended timeout values or evidence of a complete safety system.

The 2022 account describes the later Roamer as a quarter-scale wooden Tesla Cybertruck that attendees could drive over the internet. The remote operator received live camera video and the robot's location on a map. A web queue gave one person control at a time; people could wait in a browser and could choose to receive a text message when their turn began. The Hacky Racers profile identifies CYBR TRK as a follow-on from the smaller 2018 Roamer and says it began as the public-control vehicle at EMF 2022.

The Hacky Racers profile lists four 6.5-inch (approximately 165 mm), 350 W hoverboard hub motors, two original hoverboard controller boards running a fork of EFeru's field-oriented control (FOC) firmware, and a 48 V lithium-ion battery configuration. It describes two custom 6S3P packs using Samsung 30T 21700 cells, each with a 40 A continuous-rated battery management system (BMS), as well as a separate 6S4P pack set used for testing. The profile does not date every hardware detail, so treat these as reported CYBR TRK specifications, not a confirmed bill of materials for the 2022 EMF deployment.

For remote EMF operation, the profile reports browser-based control over WebSockets and live video using JSMpeg. It also says the Raspberry Pi logs hoverboard and Arduino telemetry locally through Message Queuing Telemetry Transport (MQTT), Node-RED, and Grafana. The source does not describe the complete network path, remote-control loss behaviour, or emergency-stop arrangement.

The profile describes an earlier steering setup that used a windscreen-wiper motor, potentiometer feedback, and an Arduino controller for position control, current limiting, and fault detection. It says this was later removed in favour of mechanical steering at the Hacky Racers' request for safety and competition-rule compliance. The profile also reports frequent tipping, hot battery management systems, and a 30 A fuse that can blow under hard or prolonged acceleration; it does not tie each limitation to a dated configuration.

The associated queue example uses PHP and a MySQL database on shared hosting. It demonstrates session timing and queue management for single-user-at-a-time control. The EMF 2022 Roambase page identifies the project team's village as the Roamer's home and repair shop.

===== Relevance to Robots projects =====

The Roamer is a useful reference for combining three operator-facing functions: live video, location context, and clear control ownership while users wait for access. Those patterns may inform the [[sites:chartroom:research:self-hosted-robot-coding-portal|self-hosted robot coding portal]] concept, especially event demonstrations or shared educational robots.

The queue is an access-coordination example, not a complete safety system. Any project implementation would still need to retain local command validation, operating limits, timeouts, watchdogs, and emergency-stop authority in the robot control layer.
