===== Reported design =====

Hackster Staff's 2017 report describes Pluvi.On as a rainfall-monitoring project developed during a Red Bull Basement residency in São Paulo, Brazil. It reports a split, seesaw-style bucket that tips to empty one side when it fills, then repeats with the other side. A NodeMCU based on the ESP8266 detects the bucket movement and reports rain intensity. The article describes a laser-cut acrylic enclosure and says data can be viewed through the project's application programming interface (API) or ThingSpeak.

The report presents localised flood detection as an intended application. It does not establish that the system was deployed as a flood-warning service or validated for that purpose.

===== Evidence and limits =====

The report links to an Instructables build guide in Portuguese, but that page was not retrievable during review. The available report does not identify the exact bucket sensor, volume per tip, calibration method, measurement accuracy, weatherproofing performance, or long-term test results. Do not treat the reported “rain intensity” output as calibrated rainfall rate without reviewing the build details and its calibration evidence.

This is a useful reference for a low-cost tipping-bucket sensor node with network access to rainfall data. It is a secondary project summary, not a complete build or a validated measurement system. The build has not been tested for the Robots project's use.
