===== Scope =====

This note summarises a Core Electronics tutorial for a Raspberry Pi Pico and Long Range Wide Area Network (LoRaWAN) telemetry. The tutorial is titled “Raspberry Pi Pico with LoRaWAN and The Things Network - Makerverse LoRa-E5 Module - Transmit Weather Data into IoT”. It is a third-party build guide, not a Chartroom implementation or an independently validated design.

===== Project summary =====

The tutorial demonstrates a Raspberry Pi Pico or Pico W connected over serial to a Makerverse LoRa-E5 module, programmed with MicroPython. It walks through registering the device with The Things Network (TTN), sending a test message through a LoRaWAN gateway, and extending the build into a weather and air-quality station. The expanded example uses BME280 and ENS160 sensors and a JavaScript payload decoder in TTN.

The described data path depends on a LoRaWAN gateway with coverage and the TTN service; it is not a direct local link between the sensor and an operator station. The guide discusses battery or USB power and includes a PiicoDev LiPo expansion board, but does not establish a measured energy budget or field lifetime.

===== Expanded station project =====

Core Electronics' follow-on project adds a Makerverse Nano Power Timer HAT, three AAA batteries, and an outdoor case with custom 3D-printed and laser-cut mounting parts. The author describes a scheduled cycle: the Pico and sensors wake hourly, measure with the BME280 and ENS160, send readings through the LoRa-E5 to The Things Network, then switch off through the timer board. DataCake is used for dashboard display, history, threshold email alerts, and periodic CSV reports.

The article reports a 35 nA deep-sleep current for the timer board and advertises radio range up to 10 km; these are source claims, not measurements reproduced by Chartroom. The author states that battery-life experiments were still in progress when the article was updated on 2023-12-07, so it does not establish field runtime. The dashboard and service features describe the article's 2023 setup; check current service terms, retention, and availability before relying on them.

===== Relevance and cautions =====

This is a practical reference for a small environmental sensor node and for learning the end-to-end LoRaWAN and cloud ingestion workflow. The tutorial's BME280 board is described in [[sites:chartroom:research:piicodev-bme280-atmospheric-sensor|PiicoDev BME280 atmospheric sensor]]. Compare the station with the [[sites:chartroom:research:solar-powered-wifi-weather-station-v40|Solar Powered WiFi Weather Station V4.0]], which describes a separate ESP32-based sender and receiver arrangement. For an example ventilated outdoor sensor cover, see [[sites:chartroom:research:pimoroni-outdoor-sensor-stevenson-screen|Pimoroni outdoor sensor cover (Stevenson screen)]].

Check the exact hardware revision and wiring before reuse. The tutorial notes that one image shows the wrong LoRa-E5 serial pins and says to use TX and RX, and it gives different supply wiring for USB/5 V and 3.3 V battery operation. Its example also uses device credentials; keep real credentials private and do not copy example keys into public code or documentation.

The guide's range and performance statements are source claims, not results validated by Chartroom. Radio coverage, permitted operation, sensor accuracy, enclosure suitability, and power life depend on the deployment and require separate verification. This reference does not establish suitability for marine use or adoption in project vehicle architecture.
