===== Project summary =====

The project describes a four-wheel-drive rover controlled through a web interface. Its parts list includes a Banana Pi single-board computer (with Raspberry Pi and Orange Pi alternatives suggested by the author), an Arduino Uno, an L293D motor shield, a USB webcam on a pan-and-tilt mount, and 3D-printed parts. The secondary repost describes a Python web server on the host, serial communication with the Arduino, and webcam streaming embedded in the web page. The creator's [GitHub repository](https://github.com/AIWintermuteAI/pi_rover) contains a Python host file, an Arduino sketch, and web templates; the code itself was not reviewed for this note.

===== Relevance and limits =====

This is a reference for separating a higher-level web and camera interface on a single-board computer from motor control on an Arduino. The Raspberry Pi and Orange Pi alternatives are the creator's claims, not independently verified compatibility results. The tutorial dates from 2018 and describes an older Python and Linux package stack; it is not current installation guidance. No measured radio range, video latency, runtime, environmental protection, or project integration result is established by the available sources.

For another Pi-to-Arduino communication example, see [[sites:chartroom:research:raspberry-pi-arduino-usb-serial|Raspberry Pi to Arduino USB serial link]].
