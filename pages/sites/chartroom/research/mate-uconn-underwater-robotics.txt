===== Scope =====

This page reviews the public software repository for the University of Connecticut Underwater Robotics Club's 2026 MATE ROV entry. It documents software structure and interfaces; it is not a complete vehicle build record.

===== Software architecture described by the team =====

The repository describes two main ROS 2 packages for the control laptop and onboard computer, plus a shared messages package. ROS 2 carries arm encoder values and servo commands between the two computers, and transports camera images for a video bridge. The team states that QGroundControl and the autopilot handle vehicle piloting and thrusters outside the ROS 2 drive-control path.

The README documents ROS 2 Humble on Ubuntu 22.04, a cross-machine ROS domain, topic names and message types, launch commands, camera transport through a QGroundControl video bridge, and configuration for the arm servos. These are the repository's stated 2026 setup details.

===== Relevance =====

The clear division between the pilot/autopilot path and ROS 2's arm and camera functions makes this repository useful for reviewing subsystem boundaries. Its topic contracts, two-machine setup, and camera bridge provide concrete examples for a small, competition-focused software workspace.

===== Limitations =====

The repository covers the software components documented by the team; it does not describe every electrical, mechanical, or safety interface of the vehicle. Its software division is one team's design choice, not evidence that all ROV control should sit outside ROS 2. Confirm the current season and dependencies before attempting to build or reuse the code.
