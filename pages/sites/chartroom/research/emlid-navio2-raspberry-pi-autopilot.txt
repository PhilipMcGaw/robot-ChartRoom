===== Reference summary =====

RobotShop Community's 2016 article presents the Emlid Navio2 as a hardware add-on (HAT) that lets ArduPilot run on a Raspberry Pi. It describes onboard inertial sensors, a barometer, satellite navigation receiver, radio-control input co-processor, pulse-width modulation (PWM) outputs, and serial, I²C, and analogue-to-digital converter (ADC) expansion interfaces. These are historical descriptions from the article; use Emlid's documentation for the hardware setup and software details.

Emlid's Navio2 documentation describes ArduPilot running directly on Raspberry Pi 2, 3, or 4. Its installation page lists ArduCopter, ArduPlane, ArduRover, and ArduSub among the vehicle versions in the Emlid Raspberry Pi OS image. The same documentation says that other boards, including Raspberry Pi Zero, lack the performance to run ArduCopter. These statements describe the documented Navio2 setup; they do not establish current support, suitability for a project vehicle, or support for every ArduPilot vehicle on every listed board.

===== Relevance and limits =====

Navio2 is a useful historical comparison for Linux-based autopilot designs that combine a Raspberry Pi with a hardware interface board. It shares that broad architectural pattern with Blue Robotics Navigator, but is a separate product with its own hardware, software image, support status, and setup requirements. See [[sites:chartroom:research:blue-robotics-navigator-flight-controller|Blue Robotics Navigator flight controller]] for the Navigator-specific reference.

The RobotShop post is an overview, not a current compatibility or commissioning guide. The references do not validate Navio2 for an ROV, establish environmental protection, or show that it is selected for the Robots project. Check the exact board revision, operating-system image, vehicle firmware, I/O behaviour, and product availability before considering a build.
