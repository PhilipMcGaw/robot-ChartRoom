===== Reported design =====

The project extends the Lily∞Bot educational mobile robot with four HC-SR04 ultrasonic distance sensors. It places one sensor at the front, rear, left, and right of the robot, using 3D-printed sensor mounts. The described controller is an Arduino Uno, and the motor-control code uses a TB6612 dual motor driver. The wiring instructions connect the sensors to the Arduino's 5 V and ground rails and assign separate trigger and echo pins to each sensor.

The article presents code to check the sensors and demonstrates several obstacle-response approaches: bang-bang control, proportional control that varies motor speed, and proportional control that varies movement distance. The author frames the build as an open-source robotics education resource. The related [[https://github.com/berry123/Lily-Bot|Lily-Bot repository]] contains project files and fabrication resources.

===== Relevance and limits =====

This is a compact teaching example for multi-directional proximity sensing and the relationship between sensor readings and differential-drive commands. It may be useful when comparing low-cost obstacle-detection layouts or introductory control strategies. It is a small educational robot example, not evidence of navigation performance or a validated safety function. The sources reviewed do not report measured detection reliability, stopping distance, coverage, or tests across different obstacle materials and environments.
