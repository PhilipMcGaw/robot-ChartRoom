# PCA9685 PWM/servo driver research notes

The **PCA9685** is a 16-channel, 12-bit PWM controller that provides independently controlled outputs over I²C. Adafruit's reference implementation supports Raspberry Pi, CircuitPython, and Arduino-class hosts. Multiple devices can share the I²C bus using different addresses. citeturn0search1turn0search2

## Relevance to the Robots ecosystem

The PCA9685 is useful as a reference for **offloading repetitive PWM generation from the main CPU**. A host computer can configure servo or PWM outputs while the PCA9685 generates the signals independently. This can be attractive where a Raspberry Pi is responsible for higher-level software but needs deterministic-ish PWM generation without consuming many GPIO resources.

Potential uses include:

- small robot servos;
- camera pan/tilt mechanisms;
- display or mechanical payload actuators;
- low-rate auxiliary PWM outputs; and
- prototype actuator interfaces.

The device provides up to 16 channels using only the I²C interface, and the outputs can be disabled through the OE input. citeturn0search1turn0search13

## SwarmBot and ROV

For SwarmBot, this could be useful if the platform develops several servo-driven accessories without consuming a large number of Raspberry Pi GPIOs.

For the ROV, it is potentially useful for camera/payload mechanisms, but not automatically suitable for thruster control. Propulsion control has substantially stronger requirements around update behaviour, fault response, timing, power-stage isolation, and failsafe behaviour.

## Important electrical points

The PCA9685 logic supply is separate from the servo/payload supply. Adafruit specifies VCC as the logic supply and V+ as the distributed actuator supply; these must not be confused. The outputs are logic-level PWM outputs rather than power outputs. citeturn0search13

The PWM frequency is common to all channels, so a single device cannot independently provide, for example, 60 Hz servo signals and 1 kHz LED PWM simultaneously. citeturn0search8turn0search13

## Caveats

The PCA9685 should be treated as an actuator-signal generator, not as a complete motor/servo safety controller. A higher-level controller should still own command validity, neutral/default behaviour, watchdogs, and emergency shutdown where required.
