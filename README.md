# Chartroom

Chartroom is the engineering knowledge base for the Robots project.

It brings together the architecture, design decisions, development notes, tutorials, test strategy, and project roadmap for the Robots ecosystem.

## Documentation

The published documentation is generated from the `docs/` directory using MkDocs.

## Repository structure

```text
Chartroom/
├── docs/              # Documentation source
├── mkdocs.yml         # MkDocs configuration
└── README.md          # Repository overview
```

## Scope

Chartroom documents the system as a whole and provides links and context for the individual Robots repositories, including CuttleOS, Cockpit, and DataLogger.
