# File inspection inbox

Drop files in this directory when they need to be inspected as part of work in
this repository. Tell the agent what you want checked and include any relevant
context, such as the file's source or the question it should answer.

Files in this directory are ignored by Git. They stay in this local checkout
and are not committed or pushed. Move any useful findings into the appropriate
canonical project files after inspection. Remove the dropped files when they
are no longer needed.

This inbox is local to this checkout; it does not upload files or synchronise
them with other machines.
