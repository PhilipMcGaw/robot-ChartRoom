# File inspection inbox

Drop files in this directory when they need to be inspected as part of work in
this repository. Include relevant context, such as the file's source or the
question it should answer.

This directory is a staging area, not a privacy or synchronisation boundary.
Some existing files may already be tracked by Git, and new files may be
untracked. Check the repository status before editing or cleaning the inbox.
Move useful findings into canonical project files. Move source files into
`media/sites/chartroom/` only when they are useful to retain and their source
and reuse terms have been considered. Remove files that are no longer needed
when the user requests inbox cleanup.

Changes to tracked files are included in repository commits and may be pushed
to the configured remote. Untracked files are not committed unless selected.
